EKIMA ENTERPRISES - FULL MANAGEMENT SYSTEM
===========================================

Included:
- Login screen and role selector
- Management dashboard
- Sales, Leads, Service, Parts, Bluebook, Outstanding
- Marketing, Audit, Training, PO, Warranty
- KPI cards, sales chart and management alerts
- Browser local database using localStorage
- Outstanding WhatsApp follow-up button
- JSON backup/export
- Edit/update saved records from every module
- Mobile responsive layout

RUN:
1. Keep index.html, style.css and app.js together.
2. Open index.html in Chrome/Edge.
3. Demo username: admin
4. Demo password: 1234
5. Choose a role and login.

IMPORTANT:
This is a working offline/local prototype. The login is NOT secure for production and data stays in the current browser/device.
For a real online company system, deploy a backend + database and add secure authentication, staff permissions, cloud backup, audit logs and scheduled notifications.
